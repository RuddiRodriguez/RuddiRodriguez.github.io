Make the learning steps visible

The idea is to explore different machine learning algorithms by writing their calculations directly with NumPy. I want to see how a prediction is made, how its error is measured, and how the model changes to improve the next prediction.

Each example starts small so the connection between the maths and the code stays easy to follow. NumPy handles the numerical calculations. Matplotlib draws the results; the learning itself is written in Python and NumPy.

01 / Learning a straight line

The first example uses six illustrative pairs of study hours and test scores. The model predicts a score by multiplying the hours by a slope and adding an intercept. Both values start at zero.

At each step, the script compares predictions with the example scores. It calculates how the slope and intercept should change, then updates them using a fixed learning rate. The mean squared error measures how far the predictions are from the example values.

The script measures the error again after each update. It stops when the change in error is smaller than the chosen tolerance, or when it reaches the iteration limit. Finally, it prints the fitted values and plots the line beside the data.

This example explores how the updates work and how the stopping rule behaves. The small dataset is illustrative; it does not establish a real relationship between studying and test performance.
