I could finally fit a classifier

Once a description had become a word-count row, I could pair it with its advertised seniority label and fit a model. Logistic regression was one of the first approaches. Despite its name, it is used here for classification: learning weights that help distinguish the six levels.

The early scripts separate the text preparation, vectorizer, classifier, and reporting. That keeps the initial experiment visible: prepare descriptions, hold back some rows, fit on the remaining rows, and compare the predictions with their labels.

Separating the descriptions from their answers

The outcome column becomes y; the prepared description column becomes X. The caller chooses the test proportion, and random_state=40 repeats the split for the same rows. The count-based experiment reserves 20%. This particular helper does not stratify the split or group duplicate descriptions together.

The later scripts also support a separate CSV for evaluation. A separate filename is useful organisationally, but the description overlap has to be checked to know how independent its examples are.

Learning from single words and pairs of words

The first call fits the vocabulary on training text. transform maps the test text into that vocabulary. LogisticRegression(C=1) then learns relationships between those features and the seniority labels. predict applies the fitted classifier to test rows.

C controls how strongly the coefficient sizes are restricted: changing it changes how freely the model can fit the training examples. At this stage, the displayed value is chosen directly. Later searches compare alternatives.

Trying a different way to learn from word counts

Multinomial Naive Bayes uses the term frequencies associated with each class. Its simplifying assumption makes it a useful text baseline; alpha smooths the estimated term frequencies so unseen or rare terms do not dominate through zero counts.

Both approaches receive a numeric representation of the descriptions. Changing the classifier does not remove the need to inspect the data, labels, and feature construction. The Naive Bayes file also contains later references to an undefined prediction variable; the excerpt shows the fitting step, not a claim that the whole archived script runs unchanged today.

Predictions gave me another question

A classification report separates precision—how often predictions for a level are right—from recall—how much of that level the model recovers. A confusion matrix then shows which other levels receive its mistakes.

A single split gives one result. It does not show how much the comparison changes when different examples are held back. That is the next turn in the project: cross-validation.
