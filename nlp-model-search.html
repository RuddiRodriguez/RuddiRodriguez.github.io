The classifier settings were only part of the experiment

The experiments raised choices on both sides of the model: how many terms to keep, whether to use individual words or phrases, and which classifier settings to choose. The search scripts make those choices explicit.

The archive includes an exhaustive search over logistic-regression settings, a sampled search, then a pipeline search that includes word extraction. A separate TF-IDF/Naive Bayes experiment searches its representation and smoothing together.

From chosen values to a grid of alternatives

This compares two penalties and eleven C values: 22 combinations, each evaluated through five folds. L1 and L2 restrict coefficients differently; C controls the strength of that restriction. Balanced class weights change the contribution of classes during fitting.

The vocabulary is still fitted outside this particular search. It is an intermediate step in the story, before the joint pipeline experiment. The sampled variant tries ten settings instead of every combination.

Searching the representation and classifier together

The vectorized__ prefix refers to the CountVectorizer step; clf__ refers to the classifier. Word-group ranges include single words through longer phrases, and max_features limits the retained vocabulary. The candidate space contains 420 combinations.

RandomizedSearchCV samples ten candidates and evaluates each over ten folds: 100 candidate fits, followed by the selected candidate’s refit. The full vocabulary-and-classifier pipeline is trained separately inside each fold. This is a larger methodological change than merely trying another value of C.

The script prints the selected settings and evaluates on the separate text file. Its returned predictions and search object make it possible to inspect the result, although the archive does not preserve a complete search-results table for every run.

A second joint search: TF-IDF and Naive Bayes

This file’s name mentions random search, but its active call is GridSearchCV. It compares three word-group ranges, two vocabulary limits, and six alpha values—36 candidates evaluated through five folds. fit_prior=False gives the classes equal prior probabilities instead of estimating those priors from their row counts.

The original np.linspace call supplies an integer as its fourth argument, the endpoint flag. The displayed source is retained as written; it generates six values between 0.5 and 1.5 with a truthy endpoint setting. This is one reason to read the code rather than infer the procedure from a filename.

The repeated pieces needed a home

The searches connected word extraction and fitting, but scripts still repeated preparation and reporting. The next stage brought those pieces into a shared text workflow, so the fitted process could accept descriptions and carry them through to predictions.
